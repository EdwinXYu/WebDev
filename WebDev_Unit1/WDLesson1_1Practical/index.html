Web Technologies

HTML

Hyper Text Markup Language is a markup language, it's not a programing language as said before its a mark up language. The Browser recices the HTML which renders the web page, and do whatever instructed.

CSS

CSS is a language for web page customization. CSS means Cascading Style Sheets, for well customization. CSS can help HTML showing how it can be displayed and interacted with on a web page, media, ect.

JavaScript

JavaScript is a programing language used for altering, calculate, ect on a web page. JavaScript can interact with both HTML and CSS via updating or changing. JavaScript is the 3rd programing language being used this year for WebDev.
